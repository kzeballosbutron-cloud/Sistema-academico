# Sistema Académico

## Proyecto Universitario

Sistema académico desarrollado como proyecto universitario.

### Funciones

- Inicio de sesión
- Panel académico
- Lista de usuarios
- Búsqueda de usuarios
- Lista de materias
- Diseño adaptable para celular y computadora

### Tecnologías utilizadas

- HTML
- CSS
- JavaScript
- SQL

### Base de datos

El archivo `base_de_datos.sql` contiene la estructura inicial de la base de datos y los registros de ejemplo.
